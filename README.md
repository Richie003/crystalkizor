# Crystal Kizor personal brand site

Single-page editorial site for Crystal Kizor, built from the Stage 1 assessment brief.

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```

## Stack

React 19, TypeScript, Vite, Tailwind CSS v4, Lucide icons.

## Deploy

Any static host works: upload the `dist` folder after `npm run build`, or connect the repo to Netlify, Vercel, or Cloudflare Pages with the default Vite build command (`npm run build`) and publish directory `dist`.
